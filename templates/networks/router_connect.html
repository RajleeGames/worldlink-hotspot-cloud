Before your first test

A short checklist for the technician

  1. RouterOS v7 and its HotSpot server must already be enabled on the guest bridge.
  2. Enable www-ssl for RouterOS REST. Keep it restricted to the management LAN or VPN—never the public internet.
  3. Use a dedicated RouterOS login for WorldLink. Configure a trusted HTTPS certificate where possible.
  4. WorldLink's server must be able to reach the router's IP. An administrator must allow-list it using MIKROTIK_ALLOWED_CIDRS.
  5. Test connection, then sync SOLD vouchers. Customers enter the printed code as both username and password on the MikroTik HotSpot login page.
Pilot limitations: Multi-business live EvPay auto-activation and Omada/Cudy provisioning, remote connectivity through mobile CGNAT, and live online-user polling are not implemented yet. RouterOS limit-uptime measures total connected usage, not calendar time from first login.
